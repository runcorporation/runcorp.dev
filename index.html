The lifecycle

From Agent Edit to Organisation

When agents write the code, the work that matters is understanding it, releasing it safely and keeping everyone connected to it. Each run product owns one of those stages.

1 · Write & review

Understand it

Runccc gives agents an exact map to work from and confines their edits, then shows you what each change reaches, the tests it puts at risk and the services it touches, before it's committed.

2 · Release

Ship it safely

Runcfg puts each change behind a flag or config value, so new code can be turned on, tuned or rolled back from the edge in seconds, without waiting on a deploy.

3 · Operate & coordinate

Own it

Rundoc connects every service to its team, docs, permissions and processes, and gives agents the same organisational knowledge your people use.

Built in the open

The cores of RunCCC and RunDOC are open source, so you can see exactly what your agents are working with. Run them yourself, and move to the hosted and enterprise editions when you need support.
